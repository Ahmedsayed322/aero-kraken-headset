# Aero Kraken — 3D Tournament Gaming Headset Experience 🎧

An ultra-premium, interactive 3D product showcase for a tournament-grade gaming headset, built with **Next.js 16**, **React 19**, **Three.js**, and **Tailwind CSS**.

![Aero Kraken Preview](https://github.com/Ahmedsayed322/aero-kraken-headset/raw/main/public/file.svg)

---

## ✨ Key Features

- **🎮 Interactive 3D Headset Model**: High-fidelity 3D model with realistic studio key/fill/rim lighting, ACES filmic tone mapping, and Draco geometry compression (~2.6 MB load).
- **📍 Persistent 3D Hotspot Pins**: Dynamic 3D pins pinned to exact geometry points that stay tracked across all sections and camera angles.
- **🔄 Synchronized Scroll Choreography**: Smooth, unconfused camera and model transitions mapped directly to DOM sections for each component.
- **💡 Chroma RGB Logo Lighting**: Real-time ear-cup emblem and lighting halo color switcher (Apex Crimson, Stealth Smoke, Chroma Green, Glacier Cyan) while the chassis retains its sleek tournament matte black finish.
- **🌐 Full Arabic & English Localization**: Bilingual support with complete native **RTL (Right-to-Left)** layout, mirrored 3D camera composition, and modern geometric Arabic typography (**Alexandria**).
- **🎵 Cyber Audio Engine**: Procedural Web Audio API sound generator with interactive click/hover SFX and audio frequency pulse.
- **📱 Fully Responsive**: Fluid scaling across mobile phones, tablets, laptops, and ultra-wide displays with touch-pan scrolling.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **UI Library**: [React 19](https://react.dev/)
- **3D Engine**: [Three.js](https://threejs.org/) with DracoLoader & GLTFLoader
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Typography**: [Alexandria](https://fonts.google.com/specimen/Alexandria) (Arabic) & [Manrope](https://fonts.google.com/specimen/Manrope) (Latin)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: Canvas Confetti & Web Audio API

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Ahmedsayed322/aero-kraken-headset.git
cd aero-kraken-headset
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm start
```
